# 本机硬件清单（七彩虹 B460I 黑苹果）

- 采集时间：2026-08-30
- 在用系统：macOS Ventura 13.7.8（Build 22H730，Darwin 22.6.0）
- SMBIOS 机型：**iMac20,1**（Comet Lake 桌面 + 独显的标准机型）
- 引导：OpenCore 0.9.1-RELEASE（来源：anlostsheep/hackintosh-colorful-b460i Release 3.3.0，2023-05-15）

## 一、核心硬件

| 类别 | 型号 | 关键 ID / 参数 | macOS 驱动方式与备注 |
|---|---|---|---|
| 主板 | 七彩虹 CVN B460I GAMING FROZEN V20（ITX） | 厂商 DMI：Colorful Technology | 上游建议 BIOS 1007；BIOS 默认开启 ResizeBAR（故 `ResizeAppleGpuBars=0`） |
| CPU | Intel Core i5-10400 @ 2.9GHz | 6 核 12 线程，Comet Lake-S，CPUID signature 0xA0654（family6/model A5/stepping4） | 原生支持；SSDT-PLUG 电源管理 + CPUFriend 变频 |
| 核显 | Intel UHD Graphics 630 | 8086:9BC8 | **Headless 无头模式**，`AAPL,ig-platform-id=0x3E920003`，不接显示器，仅做硬件加速/编解码 |
| 独显 | AMD Radeon RX 6800 16GB | 1002:73BF（Navi 21，RDNA2） | **原生免驱**，Metal 3；启动参数 `agdpmod=pikera`；当前显示器接此卡 |
| 内存 | 2 × 8GB DDR4（Part: 3200C18D4/8G） | 共 16GB，当前运行速率 2400MHz | B460 + i5-10400 官方上限 2666，可在 BIOS 开 XMP 后跑 2666 |
| 系统盘 | BaiZe（白泽）1TB NVMe SSD | disk0，TRIM 已启用 | NVMeFix.kext |
| 数据盘 | Synology HAT3300-12T 机械硬盘 | disk2，12TB：3×NTFS（游戏/办公/文档代码）+ 1×APFS 4.4TB（MAC 卷） | 内置 HDD |
| 显示器 | GX321UR（32 寸，6016×3384，HiDPI 3008×1692@100Hz） | 经 DP/Type-C 接 RX6800，30bit 色深 | — |

## 二、板载外设与扩展卡

| 类别 | 型号 | 关键 ID | 在用 Kext / 配置 |
|---|---|---|---|
| 板载声卡 | Realtek ALC662（音频控制器 Comet Lake PCH cAVS） | Codec 10EC:0662；控制器 8086:A3F0 | AppleALC 1.8.1，**layout-id = 7** |
| HDMI 音频 | Intel UHD630 内置 Display Audio | 8086:280B | 核显 headless 下一般不用 |
| 有线网卡 | Realtek RTL8111 千兆 | 接口 en1（192.168.1.53） | RealtekRTL8111.kext 2.4.2 |
| 无线网卡 | **Intel Wi-Fi 6 AX200**（M.2） | 8086:2723，接口 en0 | itlwm.kext 2.1.0（纯 itlwm 路线，需配合 HeliPort.app 连接 WiFi）；AirportItlwm.kext 存在但已禁用 |
| 蓝牙 | Intel AX200 集成蓝牙（USB 接口） | USB 8087:0029 | IntelBluetoothFirmware 2.2.0 + IntelBTPatcher 2.2.0 + BlueToolFixup 2.6.5；IntelBluetoothInjector 已禁用（正确） |
| USB | B460 PCH xHCI（8086:A3A3） | USBPorts.kext 定制端口 | XhciPortLimit=False（已定制，正确）；另有 XHCI-unsupported.kext |

## 三、引导与系统安全状态

| 项目 | 当前值 | 说明 |
|---|---|---|
| OpenCore | 0.9.1-RELEASE（2023-04 时代） | 仅支持到 macOS 13 Ventura 时代，远低于 macOS 15/26 要求 |
| 引导界面 | PickerMode=External + OpenCanopy（图形 logo 菜单，Blackosx/BsxOc1 主题） | Timeout=3s |
| boot-args | `agdpmod=pikera keepsyms=1 debug=0x100`（修改前，**无 -v**） | pikera 供 RX6800；后两项为 panic 保留符号 |
| SIP（csr-active-config） | 03000000 | 部分关闭（允许未签名 kext / 部分保护关闭），系统报告 SIP: Disabled |
| SecureBootModel | j185f | 注：iMac20,1 官方对应值为 **j185**；j185f 对应 iMac20,2，属小瑕疵，升级时建议改 Disabled |
| Vault | Optional | 未开启保险库 |
| FileVault | 未启用（引导配置层面无加密阻断） | — |
| ACPI 补丁 | 10 个 SSDT：AWAC/DMAC/EC/GPRW/MCHC/MEM2/PLUG/PMCR/RHUB/SBUS | Comet Lake 标准补丁集 |
| UEFI 驱动 | OpenRuntime、OpenCanopy、HfsPlus、ResetNvramEntry、CrScreenshotDxe | — |
| OC 工具 | OpenShell.efi、CsrUtil.efi | 排障可用 |

## 五、磁盘分区（系统盘 disk0 / 1TB）

| 分区 | 类型 | 大小 | 用途 |
|---|---|---|---|
| disk0s1 | EFI（MS-DOS FAT32，无卷标） | 8.6GB（实际占用约 740MB） | OpenCore 引导 + macOS 恢复启动文件 |
| disk0s2 | Apple APFS 容器 disk1 | ≈1TB | macos（系统只读卷 9.3G）+ macos - 数据（896.5G）+ Preboot/Recovery/VM |
